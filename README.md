# cache-layer-eval

Build-vs-adopt evaluation for our team's next caching layer.

This repository holds the upstream research on the candidate we are evaluating (the official open-source Redis repository), the decision checklist that drives the review, and the tracking issues for the follow-up work.

- `docs/upstream-notes.md` — facts gathered about the upstream `redis/redis` repository (full name, star count, self-description, license).
- `docs/decision-checklist.md` — the checklist used to drive the adoption decision (see the pull request from `add-research-notes`).
- Tracking issue: "Adoption decision: caching layer", with sub-issues "Benchmark latency under load" and "Review licensing obligations".
